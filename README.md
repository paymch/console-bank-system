# Console Bank System

Консольное приложение банковской системы на Python, разработанное с использованием принципов объектно-ориентированного программирования (ООП), обработки исключений и сохранения данных в формате JSON.

Проект создан в учебных целях для отработки командного Git Workflow, проектирования архитектуры ПО и работы со структурированными данными.
